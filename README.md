# ДоброРядом — фудшеринг для села

Демонстрационный учебный сайт для показа преподавателю. В проекте есть каталог бесплатных продуктов, регистрация, роли получателя и донора, публикация объявлений и бронирование.

## Запуск

Сайт размещён как статический проект. Для локального просмотра откройте `index.html` или запустите папку через Live Server в VS Code. Сборка и установка зависимостей не нужны.

## Возможности

- Просмотр каталога без регистрации.
- Регистрация и вход с выбором роли.
- Роль «Получатель помощи»: поиск и бронирование продуктов.
- Роль «Фермер / донор»: публикация и удаление объявлений.
- Личный кабинет с объявлениями и бронированиями.
- Поиск, фильтрация по категориям и сортировка.
- Адаптивная вёрстка для компьютера и телефона.
- Данные сохраняются в localStorage браузера.

## Важно

Это учебная демонстрационная версия, не production-сервис. Аккаунты и данные хранятся в браузере, пароли не защищены сервером и не синхронизируются между устройствами. Не используйте настоящие пароли и персональные данные. Для общей базы данных и реальных пользователей понадобится backend и база данных.
